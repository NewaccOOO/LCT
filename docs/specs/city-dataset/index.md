# Большой реалистичный датасет

- **Статус:** черновик
- **Размер:** Standard
- **Тип:** автоматизация
- **Исполнение:** параллельно, unlazy scope `city-dataset`, до 10 субагентов
- **Согласовал:** —

## Документы

Порядок чтения для исполнителя сверху вниз. Факт живёт в одном документе, остальные ссылаются на его ID.

| Документ | Что в нём |
|---|---|
| [brief.md](brief.md) | зачем, цели `G-`, не-цели `NG-`, бюджет, границы автономии, субагенты |
| [research.md](research.md) | распределения датасета организаторов, формат входа, что умеет генератор, что говорит против |
| [requirements.md](requirements.md) | истории `US-`, критерии `AC-` и `NFR-`, ограничения `C-`, допущения `A-`, журнал уточнений `Q-` |
| [tasks.md](tasks.md) | задачи `T-` по волнам, контракт: пресеты, тайлы, сиды, формат отчёта, журнал исполнения |
| [GATES.md](GATES.md) | гейты unlazy: у каждого `AC-` и `NFR-` свой гейт с тем же ID |

## Проверка пакета

```bash
python3 ~/.claude/skills/goal-setter/scripts/check_trace.py --input docs/specs/city-dataset
node ~/.claude/skills/unlazy/scripts/gate-lint.mjs docs/specs/city-dataset/GATES.md
node ~/.claude/skills/unlazy/scripts/gate-check.mjs --status docs/specs/city-dataset/GATES.md
```

## Промт запуска

```text
Ты автономный исполнитель. Используй скиллы goal-setter (режим исполнения, references/execution.md), unlazy, coding-flow, ponytail и write-for-humans для отчёта.
Пакет спеки: docs/specs/city-dataset/. Прочитай index.md и все документы по порядку до первого действия. Выполняй буквально.
Работай в ветке city-dataset от main, в main не пушь. Файлы из data/ в git не коммить.
Субагенты: разрешено до 10 одновременно. Запускай их одной пачкой на независимые части волны: тайлы города по одному на субагента, три сцены «густо», потом отчёт и прогоны сервиса. Каждому субагенту давай сид, папку вывода и команду проверки; его отчёт не доказательство — перепроверяй heatsynth.check и гейты сам. Генератор и проверку (T-2, T-3) пиши сам, субагентам отдавай только генерацию, прогоны и статистику.
Готово только когда `node ~/.claude/skills/unlazy/scripts/gate-check.mjs --cwd . --reverify --timeout 4000 docs/specs/city-dataset/GATES.md` печатает ALL MET и check_trace.py печатает TRACE OK.
Если сервис не выдерживает файл 3 ГБ по памяти, это находка, а не повод урезать файл: AC-1.3 и NFR-2 получают ABANDON с пиковой памятью и временем, файл остаётся от 3 ГБ.
Пользователя рядом нет: вопросы не задавай, решения фиксируй в журнале tasks.md. При конфликте побеждает спека.
```
