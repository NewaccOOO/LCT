# Эксперименты: цикл с точной подзадачей

Журнал заполняет исполнитель пакета [docs/specs/exact-subproblem](../../specs/exact-subproblem/index.md). Проверяющий сверяет его скриптом `python3 scripts/gates/exact_journal.py`: каждая строка должна сходиться с файлом выхода и коммитом.

Правила:

- одна строка — один прогон с одним набором параметров на одной сцене; сцены стенда: `dataset`, `medium-1`, `medium-2`, `medium-3`;
- «S до» — S варианта 1 без цикла на том же коммите, «S после» — с циклом; оба берутся из `variant_summary` выходов;
- файл выхода лежит в `data/out/exact/<ID>-<сцена>.geojson` и не удаляется до сдачи;
- «вывод» — одно-два предложения: принято, отклонено, хуже, почему; отрицательные результаты записываются так же, как положительные;
- параметры — все свойства `heatnet.exact.*` прогона, через запятую.
