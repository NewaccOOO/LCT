# ADR-0001: трассировка по visibility graph с эвристикой Штейнера

- **Статус:** предложено
- **Дата:** 2026-09-15

## Контекст

Нужно строить трассы прямыми отрезками с малым числом поворотов, обходить полигоны с отступом, пересекать дороги под углом не меньше 45° и объединять несколько ОКС общим стволом, где цена за метр растёт с расходом (C-1, разделы 5–7 CONSTRAINTS.md). Срок около недели (Q-1). Находки R-7…R-12.

## Варианты

- Visibility graph по рефлексным вершинам буферов + Дейкстра + Такахаши–Мацуяма + переоценка весов по расходу — плюсы: пути прямые по построению, угол пересечения это свойство ребра и проверяется при построении, реализация из готовых частей JTS и JGraphT; минусы: квадратичное построение графа, требует ограничения области и радиуса кандидатов.
- Сеточный A* или Theta* со штрафом за поворот — плюсы: просто и предсказуемо по времени; минусы: ступенчатые трассы, честная проверка угла 45° требует состояния «направление» и увеличивает граф в 8 раз (R-7).
- MILP по уличному графу уровня THERMOS или DHNx — плюсы: близко к оптимуму; минусы: нужен солвер, дни на модель, трассировка привязана к улицам, а не к свободной геометрии (R-12).

## Решение

Первый вариант: D-6, D-7, D-8, D-10, D-11. Стоимость врезок и камер не кладётся в веса рёбер, а считается после сборки дерева при сравнении вариантов целиком.

## Последствия

Проще: геометрия трасс сразу проходит проверку AC-2.13 без сглаживания. Сложнее: время построения графа зависит от числа рефлексных вершин, поэтому область расчёта ограничивается (D-6) и это первое место для оптимизации, если NFR-1 красный. Долг: эвристика не гарантирует лучшее объединение ОКС, вариант «все отдельными врезками» всегда есть как запасной.

## Как проверить соблюдение

Гейты AC-2.13 (поворотов не больше `3k + 4`) и NFR-1 (120 секунд на `medium`).
