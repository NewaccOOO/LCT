С чего начать

  1. Вверху выберите вариант решения. У лучшего самый низкий показатель S, он подписан «лучший».
  2. Во вкладке «Здания» выберите здание: появятся его трасса, продольный профиль и кнопка «Пролёт».
  3. Во вкладке «Проблемы» собраны места, где новая труба проходит по высоте слишком близко к газу, кабелю, теплосети или сквозь другую сеть. Для каждого есть подсказка, как обойти.

Открыть данные

Исходные данные и, если есть, результат трассировки — файлы GeoJSON в WGS84 (EPSG:4326). Можно просто перетащить оба файла в окно.

Какой GeoJSON подходит

У каждого объекта в properties есть номер id и тип object_type:

  • heat_network (линия, diameter), heat_chamber и source (точки) — существующая теплосеть;
  • oks_connection_point (точка, flow_tph, oks_id) и oks_future / oks_existing (полигоны, levels) — здания;
  • restriction с restriction_type: gas_pipeline, power_cable, water_supply, sewer (линии), road, tram_tracks, railway, park, water, prohibited_site, oks (полигоны).

Это тот же файл, который принимает сервис трассировки. Его обычно готовят из ГИС или выгрузки сетей.

Результат трассировки — файл, который вернул сервис (variant_summary, участки heat_network с variant_id). Объекты без object_type пропускаются, их число будет в отчёте. Пример исходных данных: скачать small-1.
