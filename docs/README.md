## Пакеты спек

| Пакет | Что сделано | Статус |
|---|---|---|
| [backend-core](specs/backend-core/index.md) | сервис на Java, CLI, генератор синтетики, валидатор | ✅ готов |
| [scenario-tests](specs/scenario-tests/index.md) | сценарные тесты S00–S14, случайный прогон sweep, отчёт | ✅ готов |
| [routing-research](specs/routing-research/index.md) | ресёрч алгоритма трассировки на синтетике: точная модель, кандидаты, правила разумной трассы | 🔄 в работе |
| [exact-subproblem](specs/exact-subproblem/index.md) | цикл с точной подзадачей: снять 5–7 ОКС, решить точно, починить спуском; прироста на датасете нет, код в ветке `exact-subproblem`, в `main` не влит | ⚠️ передано с долгом |
| [city-dataset](specs/city-dataset/index.md) | потоковый генератор файла «город» от 3 ГБ и плотных сцен с застройкой как у организаторов, прогон сервиса на них | 🔄 в работе |
| [rules-1809](specs/rules-1809/index.md) | расчёт по техническому приложению от 18.09.2026: здания-препятствия, без реконструкции и `tie_in`, ДУ по путям, повороты до 90°, новая сводка, прямые подключения города; проверщик `tools/validator/check18.py`; [отчёт о качестве до и после](testing/rules-1809-run.md) | ✅ готов |
| [city-scale](specs/city-scale/index.md) | файл «город» на 3,2 ГБ и 3,14 млн ОКС считается за 2,5 минуты по прежним правилам (после rules-1809 — 37 минут, см. его отчёт)ы: отбор под пропускную способность сети, районы параллельно, точные ускорения графа и чтения; [отчёт с замерами по этапам](testing/city-scale-run.md); выход на срезах города проходит валидатор | ✅ готов |
| [perf-2409](specs/perf-2409/index.md) | время и качество без регресса: чтение, прямые подключения и критерии города быстрее, сетка зон в графе, точные зоны отступа и срезка углов, перенос врезки к стволу, точки у трубы; датасет организаторов S 13,729 → 12,866, город 1056 → 324 с; [отчёт](testing/perf-2409-run.md) | ✅ готов |

Статус меняет агент, который ведёт пакет. Новый пакет добавляется строкой в эту таблицу.

Порядок чтения сверху вниз, точный состав у каждого пакета в его `index.md`.

| `research.md` | находки `R-` с источниками и допущения |
| `requirements.md` | истории `US-`, критерии приёмки `AC-` и `NFR-`, ограничения `C-` |
| `design.md` | решения `D-`, контракты, альтернативы |
| `adr/` | записи о принятых архитектурных решениях |
| `tasks.md` | задачи `T-` по волнам и журнал исполнения |
| `GATES.md` | гейты: у каждого `AC-` и `NFR-` своя проверка с тем же ID |
