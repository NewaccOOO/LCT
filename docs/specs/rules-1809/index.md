# Правила от 18.09: приведение расчёта к новому техническому приложению

Статус: ✅ готов, гейты G1–G5 в [GATES.md](GATES.md) закрыты 22.09.2026. Источники: «Техническое приложение ЛЦТ.docx» и «Разъяснения по вопросам ЛЦТ.docx» от 18.09.2026
(копии текста в [docs/source/tech-appendix-2026-09-18.md](../../source/tech-appendix-2026-09-18.md) и
[docs/source/clarifications-2026-09-18.md](../../source/clarifications-2026-09-18.md)).

## Что меняется

| Правило 18.09 | Было в коде | Стало |
|---|---|---|
| Все полигоны ОКС — препятствия с отступом 5/7/9 м; к своей точке один финальный прямой участок от ближайшей границы | здание с точкой подключения — цель, не препятствие | здание — препятствие; маршрут идёт до точки выхода на луче «точка → ближайшая граница», последний прямой участок без отступа к своему зданию |
| Реконструкции нет, пропускная способность сети не считается | реконструкция труб и камер, отбор ОКС по мощности ДУ1400 | удалено; в городе подключаются все, у кого есть маршрут |
| Врезка — через камеру: новая камера в точке трубы или существующая камера; объекта tie_in нет | tie_in + отдельная камера, узлы ссылались на tie_in | узлы ссылаются на новую камеру или id существующей камеры; врезка в существующую камеру 5 млн за каждый участок |
| ДУ постоянен между узлами смены расхода, предельная длина по каждому пути, ДУ не убывает к врезке | вставки на ступень выше внутри ребра | ДУ ребра = минимальный, который проходит по расходу, по монотонности и по длине пути |
| Поворот ≤ 90°, без надбавки | сетка 45°, k 1,5, лимит числа поворотов | ограничение поворота в Дейкстре и при сборке, сетка и надбавка удалены |
| Спецпроход — один прямой участок | ломаные внутри зоны перехода | узлы графа вне полосы 3 м у дорог, ломаный спецучасток отбрасывается при сборке |
| Железная дорога — запрет, 1,0 м | спецпроход 1,75 | rules.json |
| Сводка: construction_cost с камерами и врезками, existing_chamber_tie_in_count/cost, L = new_network_length, типы id как во входе | старые поля | новые поля, числовые id сохраняются |
| Неподключение только без маршрута | вариант мог оставить точку ради разнообразия; в городе — отбор по пропускной способности | варианты только с минимальным числом неподключённых; в городе прямые подключения всех точек у сети (`DirectTies`), точки дальше 11 276 м от сети недостижимы по предельной длине, дальние районы — до срока `heatnet.city.deadline` |

если их нет. Гейты — в [GATES.md](GATES.md). Сравнение качества до и после — в
[docs/testing/rules-1809-run.md](../../testing/rules-1809-run.md).
