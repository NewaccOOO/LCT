# Для агентов

Правила работы с репозиторием, раскладка каталогов и команды проверки описаны в [CONTRIBUTING.md](CONTRIBUTING.md). Прочитай его целиком перед первой правкой, затем документы в порядке из раздела «С чего начать».

Что агент делает сверх обычного контрибьютора:

- Новая задача начинается с пакета `docs/specs/<slug>/`, а не с кода. Список пакетов и их статусы — в [docs/README.md](docs/README.md), туда добавляется строка про новый пакет и там же меняется статус по завершении.
- Готовность подтверждают гейты из `GATES.md` пакета, не отчёт агента.
- Задача, которая меняет устройство сервиса, заканчивается правкой [architecture/ARCHITECTURE.md](architecture/ARCHITECTURE.md) в том же коммите. [architecture/CONSTRAINTS.md](architecture/CONSTRAINTS.md) не правится.
- Прогон, после которого появились дефекты или отчёт, записывается в `docs/testing/`.
